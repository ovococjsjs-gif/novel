# Движок и формат сценария

## 1. Файлы

| Файл | Что делает |
|---|---|
| `index.html` | Разметка, порядок подключения скриптов. **Порядок глав по умолчанию = порядок `<script>`** |
| `vn-config.js` | Персонажи, спрайты и эмоции, говорящие, допустимые `weather` / `camera` / `effect`. Общий для движка и валидатора |
| `vn-core.js` | Парсер условий и компилятор глав в плоский список инструкций. Общий для движка и валидатора |
| `script/_registry.js` | **Реестр переменных** (`VN_VARS`) и пороги концовок (`VN_THRESHOLDS`) |
| `script/<chapter_id>.js` | Главы. Имя файла = `id` главы |
| `engine.js` | Сцена, исполнение, сохранения, меню, dev-режим |
| `tools/validate.js` | Проверка сценария: `node tools/validate.js` |

## 2. Глава

```js
window.VN_CHAPTERS = window.VN_CHAPTERS || [];
window.VN_CHAPTERS.push({
  id: "day2_2_zero",                       // = имя файла
  day: "ДЕНЬ 2 · ОСТАЛОСЬ 20 ДНЕЙ",        // метка в HUD
  title: "Квартира ноль",
  subtitle: "Старокупеческий переулок · 14:10",
  bg: "bg_summer_town_day",                // короткое имя или полный путь
  bgm: "workflow.mp3",
  weather: "none",
  next: "day2_3_walk",                     // необязательно, см. ниже
  nodes: [ /* узлы */ ]
});
```

`next` — куда идти после последнего узла:
- не указан → следующая глава по порядку в `index.html`;
- строка → id главы;
- массив правил → первое подходящее: `[{ if: "route == 1", to: "w2_mirael_1" }, { to: "w2_lena_1" }]`;
- если некуда — экран «Продолжение следует».

## 3. Узлы

Состояние сцены (фон, музыка, погода, камера, спрайты) **сохраняется**, пока его не сменят.

| Поле | Значение |
|---|---|
| `speaker` | Имя из `vn-config.js` → `SPEAKERS`. По умолчанию «Рассказчик» |
| `text` | Текст. Реплики получают «— » автоматически, мысли — «…» |
| `thought: true` | Внутренняя речь |
| `sprite` | `"clear"` · `{char, emotion, pos}` · `{left:{…}, right:{…}}` · `{center:{…}}`. `pos`: left / center / right |
| `bg`, `bgm`, `weather`, `camera`, `effect` | Смена окружения. `camera`: none / ride / shake; `effect`: flash |
| `label: "имя"` | Метка — сюда можно прыгнуть |
| `jump: "цель"` | Переход **после** узла: `"метка"` в этой главе, `"chapter_id"`, `"chapter_id#метка"` |
| `set: {flag: true}` | Присвоить переменные (до показа текста) |
| `effects: {aff_lena: 1}` | Прибавить к переменным |
| `if` / `then` / `else` | Условный блок: `{ if: "lena_told_truth", then: [ … ], else: [ … ] }`. Узел с `if` ничего больше не делает |
| `choice` | Выбор, см. §4 |
| `ending: {id, title, text}` | Концовка: экран финала, запись в мета-прогресс |
| `note` | Комментарий автора, игрой не показывается |

Узел без `text`, но с `bg`/`sprite`/… — тихая смена сцены без остановки.

## 4. Выбор

```js
{ choice: { id: "d2_lena_truth", prompt: "Лена смотрит на ссадину.", options: [
  { label: "Сказать, что чуть не сбили", effects: { aff_lena: 1, inner_sight: 1 }, set: { lena_told_truth: true },
    next: [ { speaker: "Лена", text: "…" } ] },
  { label: "Отшутиться про асфальт", effects: { inner_sight: -1 }, next: [ … ] },
  { label: "Спросить про Буфер", if: "glitch_1", jump: "buffer_talk" }
] } }
```

- `id` — уникален **на всю игру** (валидатор проверяет).
- `if` у варианта — вариант скрыт, если условие ложно.
- `next` — вложенные узлы ветки; после них игра продолжается **после выбора**. `jump` — уйти в метку/главу (можно вместе с `next`, тогда после ветки).
- Без `next` и `jump` — просто продолжить.
- Клавиши 1–9 выбирают вариант. «Назад» из выбора и через выбор работает (откатываются и переменные).

## 5. Условия

Строка: `"aff_mirael >= thr.good_aff && inner_sight >= thr.good_sight"`, `"glitch_count >= 3 and not route"`, `"meta.cleared_mirael_good"`.
Операторы: `== != >= <= > <`, `&& || !` (или `and or not`), скобки, числа, `true`/`false`.
Особые имена: `meta.<флаг>` — мета-прогресс между прохождениями (`meta.cleared_<id концовки>`), `thr.<имя>` — порог из `VN_THRESHOLDS`.
Объект: `{ all: [...] }`, `{ any: [...] }`, `{ not: … }`.

## 6. Реестр переменных

## 7. Концовки и пороги

Пороги в `VN_THRESHOLDS` (откалибровать после Дней 4–7, когда будет понятен реальный разброс):

| Порог | Значение | Смысл |
|---|---|---|
| `good_aff` | 6 | Симпатия героини маршрута для хорошей концовки |
| `good_sight` | 5 | `inner_sight` для хорошей концовки |
| `bad_sight` | −2 | Ниже — плохая концовка маршрута |

- **Вход в маршрут** (решение автора 02.11, `../canon/00_decisions.md` п. 31) — по скрытому подсчёту `aff_mirael` / `aff_valeria` / `aff_lena` / `aff_taya` за Дни 0–7:
  - лидер опережает второго на `route_margin` и больше → `day7_2` ведёт к нему без меню;
  - разрыв меньше `route_margin` → выбор из двух лидеров (звонят оба);
  - лидер ниже `route_min` → земной маршрут (Лена).
  - Пороги `route_margin` и `route_min` добавить в `VN_THRESHOLDS` после выравнивания выборов Дней 1–4. Сейчас перекос: `aff_mirael` встречается в 20 вариантах, `aff_valeria` — в 6.
- **Сцены-варианты Дней 5–7:** по одной в день, по текущему лидеру (та же функция подсчёта, без меню).
- **Секретная ветка** — `glitch_count >= 3` и Саша открывает дверь под лестницей.
- **Хорошая концовка** маршрута X: `aff_X >= thr.good_aff && inner_sight >= thr.good_sight`. Плохая: `inner_sight <= thr.bad_sight`. Иначе нейтральная.
- **Истинная концовка**: `meta.cleared_mirael_good && meta.cleared_valeria_good && meta.cleared_earth_good && meta.cleared_taya_good && meta.cleared_secret_good`.
- `id` концовок: `<маршрут>_<good|neutral|bad>`, `backrooms`, `true`.

Ориентир по `inner_sight` для Недели 1: ~20 выборов, по правилу ±1 реальный максимум ~+10, у «бегущего» игрока — около 0 или ниже.

## 8. Сохранения и мета

| Ключ `localStorage` | Что |
|---|---|
| `nsnn_autosave_v2` | Автосохранение — на каждой реплике и выборе |
| `nsnn_saves_v2` | 6 слотов |
| `nsnn_meta_v1` | Между прохождениями: открытые концовки, `cleared_*`, пройденные главы и переменные на входе в каждую |
| `nsnn_settings_v1` | Настройки |

Сохранение — это снимок: глава, номер инструкции, переменные, сцена, спрайты, последние 40 шагов истории и 150 строк журнала. Старые сохранения (`*_v1`) не загружаются: формат несовместим.

**Важно при правке глав:** позиция хранится как номер инструкции. Если сильно переписать главу, сохранение внутри неё может открыться в другом месте этой главы. Это не ошибка, но для тестов удобнее начинать главу с начала через «Эпизоды».

- **Играть** — новое прохождение с нуля (спросит подтверждение, если есть автосохранение).
- **Продолжить** — автосохранение.
- **Эпизоды** — только уже пройденные главы. Глава запускается с переменными, которые были на входе в неё в последний раз.

## 9. Dev-режим

Открыть игру с `?dev=1`:
- все эпизоды открыты, у глав виден id;
- панель слева сверху: глава, номер инструкции, все переменные (изменённые — жёлтым), открытые концовки, кнопка сброса меты;
- под вариантами выбора видны эффекты и условия;
- в концовках и в «Продолжение следует» видна статистика;
- в консоли — предупреждения про неизвестные переменные, отсутствующие эмоции и битые переходы.

## 10. Валидатор

```
node tools/validate.js            # ошибки + предупреждения
node tools/validate.js --quiet    # только ошибки
node tools/validate.js --stats    # объём по главам
node tools/validate.js --strict   # предупреждения тоже валят проверку
node tools/validate.js day2_2_zero day2_3_walk   # только эти главы
```

**Ошибки** (игра сломается): нет файла фона, спрайта или музыки; неизвестный персонаж, говорящий, поле или переменная; битое условие, переход или `next`; повтор id главы или выбора; выбор меньше чем из двух вариантов.

**Предупреждения** (стиль и канон, `style_guide.md`):
- слова-маркеры, церковная лексика, не тот сезон, реальные места и бренды;
- «не X, а Y», больше одного «словно/будто» на реплику, первое лицо у рассказчика;
- длина реплик и кнопок;
- нарушение правила ±1 для `inner_sight`, щедрые `aff_*`;
- число выборов вне нормы, повторы «а что?», прозвища Лены;
- Саша в куртке без дождя;
- эмоция спрайта, которой нет (показывается запасная).

Перед каждым коммитом глав: `node tools/validate.js` без ошибок.
