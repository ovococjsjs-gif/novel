# Копии всех спрайтов персонажей для ручной вырезки фона (`sprites_for_cutout/`)

В этой папке собраны **оригинальные невырезанные копии всех 69 спрайтов персонажей** на белом фоне (плюс исходные файлы для Лены, Ники, Артёма и Дмитрия), разложенные по подпапкам:

- `sprites_for_cutout/alexander/` — **20 спрайтов Александра**:
  - Домашние (в белой рубашке и тёмных брюках): `alexander_neutral.png`, `alexander_smile.png`, `alexander_thoughtful.png`, `alexander_surprised.png`, `alexander_stressed.png`, `alexander_wounded.png`, `alexandr_happy.png`, `alexandr_sad.png`, `alexandr_shocked.png`, `alexandr_shocked_terrified.png`, `alexandr_determined_anger.png`, `alexandr_shy.png`
  - Уличные в курьерской куртке: `alexander_jacket_neutral.png`, `alexander_jacket_smile.png`, `alexander_jacket_thoughtful.png`, `alexander_jacket_surprised.png`, `alexander_jacket_shy.png`, `alexander_jacket_shocked.png`, `alexander_jacket_wounded.png` *(мокрый с разодранными ладонями в куртке)*, `alexander_courier_rain.png`
- `sprites_for_cutout/mirael/` — **16 спрайтов Мираэль** (8 крылатых `mirael_angel_*` + 8 в белом платье сестры `mirael_human_*`)
- `sprites_for_cutout/valeria/` — **12 спрайтов Валерии** (6 в истинном облике `valeria_*` + 6 в деловом костюме директора `valeria_human_*`)
- `sprites_for_cutout/taya/` — **6 спрайтов Таи** (`taya_*`)
- `sprites_for_cutout/lena/` — **5 спрайтов Лены** (`lena_*`)
- `sprites_for_cutout/nika/` — **4 спрайта Ники** (`nika_*`)
- `sprites_for_cutout/artem/` — **4 спрайта Артёма** (`artem_shank_*`)
- `sprites_for_cutout/dmitry/` — **2 спрайта Дмитрия** (`dmitry_*`)

### Куда закидывать готовые PNG с вырезанным фоном:
Ты можешь закинуть вырезанные файлы **прямо обратно в эти же папки `sprites_for_cutout/<персонаж>/`** (или напрямую в рабочие папки движка: `assets/characters/<персонаж>/transparent/` для Александра, Мираэль, Валерии и Таи и `assets/characters/` для Лены, Ники, Артёма и Дмитрия) — сохраняя те же имена файлов.
